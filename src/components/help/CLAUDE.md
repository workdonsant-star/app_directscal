# Guias de uso e operação

ProductGuide é conteúdo estático compartilhado por /docs (cliente) e /admin/guia (operação). Recebe o público explicitamente, usa links autorizados para cada papel e o sumário documental existente. Sem APIs, dados de clientes ou demonstrações. Atualize os passos quando mudar o produto; não apresente testes locais como implantação.

ProductGuide usa useAppRuntime apenas para resolver seus links; /demo/admin/guia mantém todos os atalhos na apresentação, preservando o conteúdo e os destinos de produção no runtime padrão.
