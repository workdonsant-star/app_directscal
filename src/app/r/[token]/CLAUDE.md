# `/r/[token]` — Prévia pública OMDx

## Propósito

Página pública mockada para validar como o respondente chega ao diagnóstico a partir de um link por grupo.

## Convenções locais

- Resolver o diagnóstico e o grupo pelo token no formato `${diagnostic.id}-${grupo}`.
- Mostrar introdução curta, confidencialidade e tempo estimado.
- Não renderizar formulário Likert completo nesta etapa.
- Tratar token inválido com mensagem simples para o respondente.
