# Supervisão das rotinas

GET lista ciclos, fatos e decisões da empresa para superadmin definitivo. POST recebe decisão estrita com ciclo, revisão esperada e tentativa; empresa/ator vêm de rota/sessão. Não envia mensagens. Revisão de evidência/exceção, orientação e prazo de retorno preservam a oportunidade original e passam por transação privada. Falhas não expõem detalhes internos.
