# Setores e lideranças

POST cria setor e referência de liderança Slack na mesma transação. Exige dono com sessão regular, valida contrato estrito e resolve empresa no servidor. Não aceita e-mail, nome/avatar do líder, organização ou nível de acesso do navegador. Cargo opcional é um ajuste; perfil original é consultado do Slack. Não envia convite nem cria usuários. O endpoint legado de reenvio continua disponível apenas para convites já existentes.
