# `/a/[token]` — Link de aquisição

## Propósito

Página pública mockada que captura dados B2B e libera uma prévia do módulo associado à campanha.

## Convenções locais

- Token inválido mostra estado simples de erro.
- Campanha pausada mostra estado simples, sem formulário.
- O formulário reflete campos editados pelo superadmin no mesmo navegador.
- Não renderizar experiência autenticada nem formulário Likert completo nesta rota.
