# Caso de validação OMDx

Esta pasta contém um caso **integralmente fictício** para exercitar a Fase I da metodologia DirectScal com a pesquisa “Maturidade Q4” já respondida no ambiente OMDx. Os agregados da pesquisa foram consultados em 03/11/2026; perfil, entrevistas e documentos operacionais são dados simulados, não evidência recebida de cliente.

Os arquivos `01` a `05` representam o pacote que um cliente poderia fornecer. O arquivo `06` é um registro de trabalho da consultoria para testar triangulação e limites de inferência. `00-leia-me.md` relaciona fontes, uso e pendências. Não publicar estes materiais como fatos da organização cadastrada no sistema sem substituir a identidade fictícia e validar os documentos.
